# เช็กก่อนเชื่อ — เว็บไซต์ต้นแบบตรวจข้อความน่าสงสัย

เว็บไซต์ภาษาไทยสำหรับโครงงานวิจัย **การพัฒนาเว็บไซต์ตรวจสอบข้อความหลอกลวงด้วย AI** ออกแบบเป็นต้นแบบเริ่มต้นที่เปิดใช้งานได้โดยไม่ต้องติดตั้งเครื่องมือหรือสมัครบริการ

## ขอบเขตของต้นแบบ

- วางข้อความ SMS/แชตแล้วกดวิเคราะห์ เพื่อดูระดับความเสี่ยงเบื้องต้น จุดที่ตรวจพบ เหตุผล และคำแนะนำ
- ใช้กฎคำสำคัญ JavaScript ที่อ่านและแก้ไขได้ ไม่ได้เชื่อม AI หรือบริการภายนอก
- ประมวลผลในเบราว์เซอร์ ไม่มี backend, analytics, cookies หรือการบันทึกข้อความ
- ผลลัพธ์เป็นเพียงสัญญาณประกอบการพิจารณา ผลความเสี่ยงต่ำไม่ได้ยืนยันว่าปลอดภัย

## เปิดใช้งานในเครื่อง

1. เปิดโฟลเดอร์นี้ใน VS Code หรือโปรแกรมแก้ไขโค้ด
2. เปิด `index.html` ในเบราว์เซอร์
3. ลองปุ่มตัวอย่าง หรือวางข้อความของคุณเองแล้วกด **วิเคราะห์ข้อความ**

ไม่ต้องใช้คำสั่งติดตั้งแพ็กเกจ เว็บใช้ HTML, CSS และ JavaScript ปกติ ฟอนต์ Google Fonts เป็นส่วนเสริม หากไม่มีอินเทอร์เน็ตจะใช้ฟอนต์สำรองในเครื่อง

## แก้ไขกฎ

แก้รายการ `signals` และน้ำหนักคะแนนใน `app.js` ได้ ระดับสูงเริ่มที่ 5 คะแนน ระดับควรระวังเริ่มที่ 2 คะแนน ควรทดสอบกับทั้งข้อความปกติและข้อความน่าสงสัย และอธิบายข้อจำกัดเหล่านี้ในรายงานวิจัย

## เผยแพร่เมื่อพร้อม

ต้นแบบนี้เป็นไฟล์ static สามารถนำไปวางบนบริการโฮสต์ static ที่โรงเรียนอนุมัติได้ โดยไม่ต้องมีเซิร์ฟเวอร์ประมวลผลข้อความ ก่อนเผยแพร่:

1. ขออนุญาตครู/โรงเรียนและผู้ดูแลโดเมนหรือบัญชีโฮสต์ก่อน
2. เปลี่ยน `example.com` ใน `robots.txt` และ `sitemap.xml` ให้ตรงกับโดเมน HTTPS จริง
3. หากเปลี่ยนเส้นทางหน้าเว็บ ให้แก้ `<loc>` ใน `sitemap.xml` ให้เป็น URL จริง
4. เปิดเว็บที่เผยแพร่แล้วตรวจว่า HTTPS ใช้งานได้ ไฟล์ `robots.txt` และ `sitemap.xml` เข้าถึงได้ และหน้าทำงานบนมือถือ
5. เพิ่ม property ของโดเมนใน Google Search Console ด้วยบัญชีที่ได้รับอนุญาต ยืนยันการเป็นเจ้าของตามวิธีที่ Google แสดง
6. ส่ง URL sitemap ใน Search Console แล้วใช้ URL Inspection เพื่อตรวจหน้าแรกและขอจัดทำดัชนีเมื่อพร้อม
7. ตรวจรายงาน indexing ในภายหลัง การส่งคำขอไม่ได้รับประกันว่าจะปรากฏในผลค้นหาหรือปรากฏทันที

ยังไม่มีเว็บสาธารณะหรือโดเมนจริง จึงยังส่ง sitemap/คำขอจัดทำดัชนีไม่ได้ และไฟล์ตัวอย่าง `example.com` ใช้ได้เพียงเป็น placeholder เท่านั้น

## ไฟล์

- `index.html` — หน้าเว็บและข้อมูล SEO ภาษาไทย
- `styles.css` — รูปแบบ responsive
- `app.js` — กฎวิเคราะห์ตัวอย่างและการโต้ตอบ
- `robots.txt`, `sitemap.xml` — ไฟล์เตรียม SEO สำหรับแก้โดเมนหลังเผยแพร่

## ตรวจสอบ URL

มีช่องตรวจ URL เพิ่มเติม โดยดูสัญญาณจากรูปแบบโดเมน โปรโตคอล HTTP, IP, punycode, บริการย่อลิงก์ และพอร์ตที่ไม่ปกติ การตรวจทำในเบราว์เซอร์และไม่เปิดหรือเรียก URL ปลายทาง ไม่ได้ตรวจเนื้อหาเว็บไซต์หรือเทียบฐานข้อมูลภัยคุกคาม จึงใช้ยืนยันความปลอดภัยไม่ได้ ทั้ง URL ปกติและ URL ที่ถูกแจ้งเตือนอาจประเมินผิดได้


ตัววิเคราะห์ข้อความแสดงคำที่จับคู่ได้จริงจากข้อความที่ผู้ใช้วาง พร้อมเหตุผลที่ผูกกับกฎแต่ละข้อ ผลไม่ได้แต่งเนื้อหาข้อความขึ้นใหม่ แต่กฎยังเป็นแบบง่ายและอาจจับบริบทผิด เช่น การยกตัวอย่างคำเตือนหรือการปฏิเสธการหลอกลวง ไม่มีการเชื่อม API ตรวจสอบเว็บจริงในเวอร์ชันนี้ เพราะยังไม่มี provider/API key/backend ตั้งค่าไว้
